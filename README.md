## Описание проекта
Веб-приложение реализует интерактивный профориентационный тест (3 методики, 76 вопросов), рассчитывает персональные результаты и формирует отчёт в PDF. Пользователь может отправить отчёт на e-mail, а администратор может просматривать статистику прохождений.

В подготовленную папку включены только исходные файлы проекта и служебные файлы репозитория. Локальные артефакты разработки, такие как `backend/node_modules`, `.env` и накопленная статистика, в публикацию не входят.

## Цели и задачи
- Провести профориентационное тестирование абитуриента в удобном web-интерфейсе.
- Сформировать интерпретацию результатов и рекомендации по направлениям обучения.
- Автоматизировать отправку отчёта на электронную почту.
- Собирать агрегированную статистику прохождений.

## Функциональные возможности
- Чат-интерфейс прохождения теста.
- Ввод ФИО и e-mail перед началом тестирования.
- Расчёт профиля по методикам RIASEC, Климова и учебным направлениям.
- Вывод итогов в интерфейсе.
- Экспорт отчёта в PDF.
- Отправка PDF-отчёта на e-mail через SMTP.
- Раздел статистики (summary + таблица прохождений).

## API (основные endpoint)
- `GET /api/health` — проверка состояния сервиса.
- `POST /api/v1/test/calculate` — расчёт результатов теста.
- `POST /api/v1/results/email` — отправка отчёта на e-mail.
- `POST /api/v1/results/pdf` — генерация PDF-отчёта.
- `GET /api/v1/stats/summary` — агрегированная статистика.
- `GET /api/v1/stats/events` — список последних прохождений.

## Подготовка и запуск

Клонируйте репозиторий:
### 1. Backend
1. Перейти в папку `backend`.
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Создать файл `.env` на основе `.env.example` и заполнить SMTP-параметры.
4. Запустить сервер:
   ```bash
   npm start
   ```
health-check: http://localhost:8787/api/health

### 2. Frontend
Перейти в корень проекта и поднять локальный сервер, например:
```bash
python -m http.server 5500
```
Затем открыть:
http://localhost:5500/frontend/index.html

Страница статистики открывается отдельно по прямому адресу:
http://localhost:5500/frontend/stats.html

## Тестирование
### Backend
Для запуска встроенных проверок:
```bash
cd backend
npm test
```

Проверяются:
- расчёт результатов для полного набора ответов
- корректность нормализации минимальных ответов
- режим `dry-run` для e-mail без SMTP
- корректная работа endpoint `POST /api/v1/test/calculate`
- отказ сервера при неполном наборе ответов
